# OnlyNews Prompt

個人用ニュースアプリ **OnlyNews** を、AIコーディングエージェント（Codex等）で再構築するための完成版プロンプトを公開するリポジトリです。

## このリポジトリについて

OnlyNewsは、RSSなどからニュースを取得し、広告や不要な要素をできるだけ避けて、本文中心で読めるAndroidニュースアプリとして試行錯誤しながら制作しました。

最初から完成した仕様書があったわけではありません。実機で使いながら、

- 記事をタップしても開かない
- 元サイトの広告まで表示される
- 特定カテゴリの記事数が0件になる
- あるカテゴリを直すと別カテゴリの記事数が減る
- サムネイルにサイトロゴが出る
- 画面がステータスバーやナビゲーション領域と重なる
- GPSだけでは地域判定を誤る
- オフラインでも読みたい
- 自動更新したい

といった問題や要望を一つずつ見つけ、修正を重ねました。

このリポジトリの `PROMPT.md` は、その試行錯誤を一つのプロンプトに圧縮したものです。

## ファイル

- [PROMPT.md](./PROMPT.md) — OnlyNews完全再現プロンプト 最終版

## 使い方

1. `PROMPT.md` を開く
2. 全文をコピーする
3. Codexなど、リポジトリを編集できるAIコーディングエージェントに渡す
4. 新規Androidプロジェクト、または既存プロジェクト上で実装させる
5. 実機で動作を確認し、必要に応じて自分向けに調整する

## 注意

- このリポジトリにはOnlyNews本体のソースコードは含まれていません。
- Androidアプリの署名キー、APIキー、パスワードなどの秘密情報も含まれていません。
- Webサイトの本文取得可否は、各サイトの構造や仕様変更によって変わる可能性があります。
- RSSやWebコンテンツの利用にあたっては、各提供元の利用条件を確認してください。
- このプロンプトは「一発で必ず完全なアプリが生成される」ことを保証するものではありません。AI開発における要件定義・再現実験用の素材として公開しています。

## 背景

制作過程はnoteの記事としてまとめる予定です。

テーマは、単に「AIにコードを書かせた」という話ではなく、

**使う → 違和感を見つける → 言葉にする → AIに直させる**

という繰り返しの中で、最終的に仕様書そのものが育っていった、という過程です。
